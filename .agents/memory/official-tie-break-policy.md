---
name: Official tie-break policy
description: The approved, transparent ordering used when complete entries have equal three-judge final averages.
---

For complete entries with equal three-judge final averages, decide placement by higher average Criterion 1, then Criterion 2, then Criterion 3, then lower average deductions. If every scored measure remains equal, use school code in ascending order as the final deterministic fallback. Mark every entry in the equal-final-score group as having received the tie-break policy, with the first criterion that separated the group.

**Why:** Awards need one consistent, auditable result instead of relying on unstable ordering or an undocumented manual decision.

**How to apply:** Keep the policy and per-entry tie-break status in the tabulation API contract so the Group, Solo, and dashboard leaderboards all describe the same official result.
